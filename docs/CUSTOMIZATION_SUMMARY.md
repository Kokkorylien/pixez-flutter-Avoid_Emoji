# 相对初始版本的累计改动

截止版本：**PixEz Emoji 1.9.89-emoji.3（versionCode 516）**。
比较基准为开始定制时的上游提交 `f11be4d`（Android `0.9.114 Simulacrum`）。
以下覆盖文件名定制首版及后续阅读更新，不表示已合入上游此后的更新。

## 1. 文件名与外置存储卡兼容

- 保存文件前处理文件名及作者目录名中的 emoji，应对部分 TF/SD 卡无法创建 emoji 名称文件的问题。
- 支持三种处理方式：替换为下划线（默认）、剔除、替换为离线英文名称。
- 英文名称可选首字母小写或大写，例如 `🐟️` → `fish` / `Fish`；多词名称用下划线连接，未识别表情回退为 `_`。
- 覆盖组合表情、肤色、旗帜等序列；剔除后名称为空时保留 `_`，避免丢失文件名或目录层级。
- 普通空格、中文、日文保留，命名规则编辑器恢复空格输入。
- 同样作用于自定义 JS 命名、旧任务重试、GIF/ZIP 导出、头像及小说导出；保存与查重使用相同处理规则。
- 存储设置提供模式选择、英文首字母大小写及实时命名预览，并保存所选设置。

例如命名规则 `{illust_id}_p{part} {title}`、标题 `夏日🐟️`，英文模式得到
`123_p0 夏日fish.jpg` 或 `123_p0 夏日Fish.jpg`。

## 2. 阅读画质与原图复用

以下阅读改动针对安卓 Material 界面的图片阅读器。

- 阅读默认使用普通预览图（Pixiv large），旧版“阅读画质”设置不再强制联网请求原图。
- 优先读取已保存的原图，再复用已完成的原图缓存；都没有时加载普通预览。
- 点按 HD，在当前页原图／低清之间切换；长按 HD，为本作品全部图片启用原图，翻到时加载。
- 自动读取本地原图后也可点按 HD 回退低清。手动低清选择在本次阅读中有效，下载完成不会覆盖该选择；重新进入阅读恢复默认规则。
- 低清缓存已清理时重新缓存预览；等待期间保留原图。切换失败保留当前图片，可恢复网络后重试。

## 3. 保存目录、图源切换和缓存清理

- 安卓原图保存记录实际文件 URI，支持普通目录及 SAF 授权的外置卡目录，后续阅读可直接复用下载目录中的原图。
- 旧下载根据下载记录及当前命名规则查找相关文件，不遍历整张卡。原图丢失、卡不可用或无读取权限时回退普通预览。
- 当前前台阅读页的原图下载完成后，先解码首帧，保留旧图直到新图完成显示，再迁移文件；保存成功不再触发第二次图源切换。
- 目标文件关闭、可读且位置记录成功后，才清理重复的低清缓存、原图缓存和中转文件；保存失败保留中转原图并标记失败。
- 退出阅读、翻离当前页或进入后台会解除显示交接等待，继续保存，不要求后台页面绘制一帧。
- 保存时复用作者目录及分级目录规则，写入完成后才标记下载成功；下载流完成通知只处理一次。

上述调整针对阅读下载后两次闪黑的问题；逐帧自动检查已通过，真实设备上的最终观感仍需确认。

## 4. 阅读中直接下载

- 点按下载按钮保存当前图。
- 长按图片或下载按钮，打开当前图下载／多选下载菜单，选择后继续留在阅读器。
- 多选界面提供页码、缩略图及全选，复用原下载队列和保存规则。
- 保留长按 HD 的全部原图操作，避免 Tooltip 抢占长按手势。

## 5. AI 作品快捷筛选

- 动态速览、推荐和搜索增加一键显示／隐藏 AI 生成作品入口，复用并持久保存原本的本地 AI 屏蔽设置。
- 根据 Pixiv 的 AI 作品标记过滤，保留已加载源数据；取消隐藏可立即恢复已加载作品，无需为切换开关销毁列表并重新请求全部数据。
- Pixiv 账号或服务端本身未返回的作品不在本地恢复范围内。

## 6. 安装、源码与验证

- 定制应用名 PixEz Emoji，包名 `com.perol.pixez.avoidemoji`，可与原版共存，使用独立数据。
- 最低 Android 7.0（API 24），提供 ARM64 安装包及包含 ARM32／ARM64／x86_64 的通用包；同一签名支持覆盖升级旧定制版。
- 新增针对命名、设置、保存通道、图源选择、缓存交接及阅读手势的测试，并保留 Unicode 英文名称数据的生成脚本和许可。
- 首版文件名处理已由用户在原平板 TF/SD 卡案例中实机确认；后续阅读功能完成自动检查与签名 release 构建，不能据此认定所有真实设备均已验证。
- APK、SHA256 校验文件和安装说明放在 [Releases](https://github.com/Kokkorylien/pixez-flutter-Avoid_Emoji/releases/latest)，源码中不包含签名私钥、本机配置或安装包。

具体测试范围见[验证记录](VALIDATION.md)，阅读功能的复现与验收操作见[阅读说明](READER_CHANGES.md)。
